# Quick Start Guide

## What's Included

This setup includes three new files to make getting started easier:

### 1. `requirements.txt`
Contains all Python dependencies with pinned versions for reproducibility:
- Web framework (FastAPI, Uvicorn)
- Data processing (Pandas, NumPy)
- Database (DuckDB)
- Machine learning (scikit-learn, LightGBM)
- Geospatial libraries (GeoPandas, Shapely)
- Testing (pytest)

### 2. `quickstart.sh`
Automated setup script that:
- ✅ Checks Python version
- ✅ Creates virtual environment (`fastapi_env`)
- ✅ Installs all dependencies
- ✅ Checks for required data files
- ✅ Checks for trained model files
- ✅ Initializes database tables
- ✅ Creates `.env` configuration
- ✅ Generates `start_server.sh` for easy launching

### 3. `start_server.sh` (generated by quickstart)
Convenience script that:
- Activates the virtual environment
- Sets environment to development mode
- Starts the FastAPI server
- Shows helpful URLs

## Usage

### First Time Setup

```bash
# Clone the repository
git clone https://github.com/gefgu/oficinas2-central.git
cd oficinas2-central

# Run the quickstart script
./quickstart.sh
```

The script will guide you through the setup process and alert you to any missing files.

### Starting the Server

After running quickstart, you can start the server anytime with:

```bash
./start_server.sh
```

Or manually (recommended for development):

```bash
source fastapi_env/bin/activate
cd server
export PRODUCTION_MODE=false
# Use uvicorn with --reload for automatic server restart on code changes
python3 -m uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

### Running Tests

```bash
source fastapi_env/bin/activate
pytest server/test_main.py -v
```

## What If Files Are Missing?

The quickstart script will check for required files:

### Data Files (in `dados/`)
- `Curitiba_resolution_10.geojson` - H3 hexagon grid
- `bairros_curitiba.zip` - Neighborhood boundaries

**Solution**: Obtain these files from the project source or geographic data providers.

### Model Files
- `modelos/lgb_purpose_model.pkl` - Purpose prediction model
- `modelos/lgb_purpose_encoders.pkl` - Label encoders
- `server/random_forest_model.pkl` - Transport mode model

**Solution**: Train models by running the Jupyter notebooks:

```bash
source fastapi_env/bin/activate
# Install notebook dependencies (if not already installed)
pip install jupyter matplotlib seaborn contextily

# Start Jupyter
jupyter notebook notebooks/
```

Then run:
1. `modelo_proposito_foursquare.ipynb` - Trains purpose classifier
2. `modelo_de_transporte.ipynb` - Trains transport mode classifier

## Troubleshooting

### Virtual Environment Already Exists

The quickstart script will ask if you want to recreate it. Choose:
- **Yes (y)**: Delete and recreate (useful if dependencies changed)
- **No (n)**: Use existing environment (faster)

### Python Version Issues

The project requires Python 3.8+. Check your version:

```bash
python3 --version
```

### Permission Denied

If you get "Permission denied" when running scripts:

```bash
chmod +x quickstart.sh
chmod +x start_server.sh
```

### GeoPandas Installation Issues

On some systems, GeoPandas requires system-level dependencies:

**Ubuntu/Debian:**
```bash
sudo apt-get install gdal-bin libgdal-dev
```

**macOS (with Homebrew):**
```bash
brew install gdal
```

### Database Already Exists

The database files (`dados.db` or `dados_test.db`) will be created automatically. If you want to start fresh:

```bash
rm server/dados_test.db
cd server
python3 db_commands.py
```
